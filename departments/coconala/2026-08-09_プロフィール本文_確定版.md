## 3回目の版からの変更点（4箇所）

### 1. 「対応できないこと」の4番目を戻し、補足をリストの外へ（指摘済み）

**変更前**
```
　・進学・転職・結婚などについては、お名前から見た材料はお出ししますが、結論の指示はいたしません。
```

**変更後**
```
　・進学・転職・結婚などを「する / しない」の結論としてお伝えすること

進学・転職・結婚などについては、お名前から見た材料はお出ししますが、結論の指示はいたしません。
```

**理由**：リスト冒頭が「お受けできません」なのに、4番目だけ「お出しします」という受けられる話になっていた。
流し読みで「進学・転職・結婚は受けてもらえない」と読まれて取りこぼす、
逆に「受けてもらえる」と読んだ購入者が結論を求めてきたときに揉める、の2つの実害がある。
リストを「できないこと」だけで揃え、直後に受け皿の文を置いた。

### 2. 「姓名判断は 2024年から」の半角スペースを削除（指摘済み）

→ 「姓名判断は2024年から」

### 3. 「旧字体や異体字のご希望があれば」→「戸籍上の字が旧字体・異体字の場合は」（追加）

**理由**：「■ 鑑定でみているもの」に「画数は旧字体（正字）を基準に数えます」を追記したことで、
**旧字体が既定になった。** その状態で「旧字体のご希望があれば」と書くと、
既定なのか選択肢なのかが読み手に分からなくなる。

聞きたいのは希望ではなく**戸籍上の実際の字**（澤なのか沢なのか）なので、そう書き換えた。
鑑定の精度に直結する情報でもある。

**この3は指摘に含めていなかった追加の変更なので、不要であれば元に戻してよい。**

### 4. 対応時間の行末の「。」を削除（表記統一）

同じ箇条書きの他の項目に句点がないため揃えた。
