## このファイルの書き方

**本文は一行も写していない。** 記録しているのは、
「どの格をどう出すか」「何を見るか」という**手順と考え方**だけ。
言い回し・解説文・各数の説明は、この部屋に持ち込まない。

これは熊崎式のときに決めた規律をそのまま適用したもの
（`2026-08-14_型の棚卸し課題.md`「原典の扱い」）。**本が変わっても規律は変わらない。**

## 奥付の記載と、その意味

奥付に、**無断での転載・複製・複写・翻訳を禁じる旨**が書かれている。

**これは熊崎式の禁制とは種類が違う。** 混同しないよう分けて書く。

| | 熊崎式の書籍 | 田口本 |
|---|---|---|
| 何を禁じているか | **承認を得ない職業的応用**（実践そのもの） | **複製・転載**（表現の複写） |
| 性質 | その流派の内部規定 | 著作権の通常の表示。どの本にもある |
| こちらへの影響 | **考え方を学んでも、商用に使えない** | 写さなければよい。**読んで学ぶことは妨げない** |

つまり田口本は、**読んで考え方と事実を受け取り、自分の言葉で書く**という
これまでのやり方で、通常の参考文献として扱える。**ここが熊崎式と決定的に違う。**

### 一冊を通して確認した結果（確定）

**熊崎式の禁制五則にあたる記述は、この本には無い。** 一冊分を最後まで確認した結果である。

奥付にあるのは、無断での**転載・複製・頒布・公衆送信・翻訳・翻案**を禁じる旨の表示だけ。
これは占いの本に限らず、ほとんどの本にある通常の表示である。
**この体系を学んで職業に用いることを止める規定は、どこにも無い。**

### それでも、抵触しない書き方を徹底する（人の指示）

> 特に記載はありませんが、問題になっても嫌なので抵触しないように鑑定結果を出してください。

**この指示を型に落とし込んだ。** 型の 5-6 に「参照した文献すべてに、同じ規律を適用する」を
追加し、鑑定担当とチェック担当にも同じ観点を入れた。

要点は、**禁止されているのは複写だけでなく作り替えて使うことも含む**という点。
言葉を入れ替えただけの文は、自分で書いたことにならない。
だから**元の解説文を手元に置いて言い換えるのではなく、お名前から書き起こす。**
出てくる文章がそのお客様固有のものになれば、なぞりようがない。

### ただし流派名は名乗らない

著者は「純正運命学会」という名のある団体を率いている。
熊崎式のときと同じく、**特定の流派名を掲げて商品を出すことはしない。**
考え方を参考にすることと、看板を借りることは別である。

## 方法の骨格

### 格の分け方（五運）

熊崎式の五格と**構造は同じで、呼び名が違う。**

| 田口流 | 熊崎式でいうと |
|---|---|
| 祖運 | 天格 |
| 主運 | 人格 |
| 初運 | 地格 |
| 助運 | 外格 |
| 総運 | 総格 |

型の0節で「主運・副運・前運・後運という呼称は使わない」と決めたが、
**田口流の呼称も採らない。** どちらも流派固有である。天格・人格などの一般的な名前で通す。

### 画数の数え方 ★現行の型と正反対

**楷書体をそのまま数える。** 旧字体に直さない。部首を本来の字の画数に読み替えない。

| 部首 | 田口流 | 現行の型（旧字体・霊画） |
|---|---|---|
| さんずい | 3画 | 4画（水として） |
| けものへん | 3画 | 4画（犬として） |
| てへん | 3画 | 4画（手として） |
| しめすへん | 4画 | 5画（示として） |

**ここが今回の最大の発見。** この数え方を採ることに決めた（後述）。

### 三運の調和

祖運・主運・初運の3つを**五行に置き換えて、関係を見る。**
熊崎式の三才配置と、見る対象（天・人・地の3格）も方法（五行の相生相剋）も一致する。

**五行に置き換えて関係を見ること自体は、この本の発明ではない。**
相生相剋は広く共有された枠組みで、複数の流派が同じことをしている。
だから**ここは共通土台として扱える**（`2026-08-15_姓名判断の流派共通性リサーチ.md` の判定とも整合）。

### 成功運と安定運

| 田口流 | 出し方 | 熊崎式でいうと |
|---|---|---|
| 成功運 | 祖運 × 主運 | 成功運（天格×人格）と同じ組 |
| 安定運 | 主運 × 初運 | 基礎運（人格×地格）と同じ組 |

**見る組み合わせは同じ。判断のしかたが違う。**

- 熊崎式：一の位の組ごとに判定文を持つ（50通りの表）
- 田口流：五行に置き換えて、5×5の関係（相生・相剋・比和）で判断する

**この違いは、依拠替えにとって有利に働く。**
落とすと決めた50通りの判定表を、**表として持ち越すことなく、
五行の関係という一般的な枠組みで置き換えられる。**
5×5＝25通りは、相生相剋という共有された規則から導けるので、
特定の本の記述に依存しない。

### 陰陽

**採る。ただし従属させている。**

画数が吉数で三運の調和が良ければ、陰陽が凶でもその凶は作用しない、という順位づけ。
**陰陽は単独では効かない補助的な要素**という位置づけになる。

これは型の未決事項（0節★陰陽配列）に対する材料になる。
「採る／採らない」の二択ではなく、**「採るが従属させる」という第三の形がある**と分かった。

### 字音五行

**画数とは別に、音でも見る。**

| 行 | 五行 |
|---|---|
| か行 | 木 |
| た行・ら行・な行 | 火 |
| あ行・わ行・や行 | 土 |
| さ行 | 金 |
| は行・ま行 | 水 |

現行の型には無い視点。採るかどうかは別途判断する。

### 事典としての作り

画数別・読み方別の漢字一覧を持つ。**引くための本**として作られている。
運用上、画数を確認する道具として有用。

## 決着：楷書体をそのまま数える（2026-08-15 決定）

**この本の数え方を採る。** 型の1節を書き換えた。**新旧の併記もやめる。**

### 推薦を途中で変えた経緯

最初は「旧字体を基準とし、楷書体を併記する」を推した。理由の一つに
**「無料ツールと数字が違うことが、有料である理由になる」**を挙げていた。

**これは筋が悪い。** 数字が違うことは価値ではない。お客様が払っているのは読み解きに対してである。
しかも「なぜ他と数字が違うのか」の説明は、**どちらを選んでも発生する**（旧字体で数える流儀は
世に多い）ので、そもそも決め手にならない。

残った理由は「これまでの蓄積」だけだったが、**それは切り替えの費用の話であって、
どちらが良いかの話ではない。**

### 採る理由

| | 中身 |
|---|---|
| **間違いが一種類まるごと消える** | 「この字の正字は何か」の判断が要らない。書いてあるものを数えるだけ |
| **お客様が検算できる** | 数えれば一致する。「根拠を示す」「断定しない」という型の姿勢と噛み合う |
| **つまみ食いでなくなる** | 土台に推した本の中核の手順を採らない、という弱点が消える |
| **戸籍の字体をそのまま扱える** | 髙・﨑・邊などを「本当は◯◯ですが」と言い換える必要がない |

### 失うもの

- **出品ページの「新旧併記」の約束を撤回する必要がある**（人の作業）
- 旧字体で見てもらった経験のあるお客様には、数字が違って見える
- 「旧字体のほうが本格的」という見え方は多少落ちる

### 文屋本を待たなかった理由

「2冊目の立場を見てから決める」と書いていたが、**待たずに決めた。**

0節で「自流として選択を宣言する」という立場を既に採っている。
**文屋本が旧字体側でも、「うちは楷書体を採る」と宣言すればよいだけ**なので、
待つ意味がない。**1〜4節はどのみち依拠替えで組み直すため、いま決めるほうが安い。**

### 影響範囲

部首の扱いが変わるので、**珍しい字だけでなく、ほとんどのお名前で数字が動く。**
納品済みの2件も現在の基準とは合わなくなる。追いかけて訂正はしないが、記録に残す。

### 積み残し：漢数字の扱い ★

「書かれているものを数える」の原則からは、十＝2画になる。型には暫定でそう書いた。
**数の意味で数える流儀も広く行われているため、この本での扱いを人が確認すること。**

## 81数の吉凶：一覧は存在した（2026-08-15 訂正）

**「一覧が無い」は誤り。** 書き起こしを検索して確認した。

第5章が丸ごと画数ごとの記述になっていて、**各画数に ○ / △ / × の印**が付いている。
本文にも、○が吉数・×が凶数である旨の断り書きがある。

**表の形をしていないので見落としやすい。** 「一覧表」を探すと見つからないが、
**章そのものが一覧**になっている。

### 型と同じ三区分だった

| 田口本 | 型 |
|---|---|
| ○ | 吉数 |
| △ | 吉凶が相半ばする数 |
| × | 凶数 |

**二値ではなく三区分**という構造自体が一致した。これは型にとって大きい。

### 突き合わせた結果（部分）

書き起こしから印を機械的に拾えたのは **27／81**。残りはOCRが印を落としている。

| | 件数 |
|---|---|
| 一致 | **24件** |
| 不一致 | **3件** |

**不一致の3件**

| 画数 | 型 | 田口本 |
|---|---|---|
| 49 | 相半ば | **凶** |
| 71 | 相半ば | **吉** |
| 76 | **凶** | **吉** |

49と71は、型が「相半ば」に置いている数が二値のどちらかに振れたもの。
**76だけは、吉と凶で正面から逆**である。

### この結果の限界

- **拾えたのは3分の1。** 残り54件は本を引かないと分からない
- 書き起こしはOCRを含み、**別の箇所で明らかな乱れも見つかっている**
  （ある画数の印と本文の内容が噛み合っていない箇所があった）
- したがって**この3件も、本で直接確認するまで確定ではない**

### それでも言えること

**三区分の構造は共有されている。** 一致率も、拾えた範囲では9割近い。
「型の吉凶区分が一冊にしか出どころがない」という状態は、**部分的に解消した。**

### 残る作業

**本を開いて、54件の印を確認する。** とくに次の3つを先に見る。

1. **76画**（吉と凶で正面から逆）
2. **49画・71画**（相半ばがどちらに振れているか）
3. **△が付いている数の一覧**（型の相半ば8つと一致するか）

## 次に確認すること

田口本を手元に置いた状態で、以下は読めば埋まる。

1. **81数の残り54件の印**（上記のとおり。最優先）
2. **霊数を採るか**（姓一字・名一字のときの扱い）
3. **性別で判断を変えているか** — 第5章は男性・女性を分けて書いているため、
   **分けている可能性が高い。** 型は「性別で吉凶を変えない」と決めたので、
   食い違うなら**こちらの選択として宣言する**形になる
4. **各格が司る年齢をどう配当しているか**
5. **漢数字の扱い**（十は2画か、10か）
