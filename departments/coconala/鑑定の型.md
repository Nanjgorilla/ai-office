## 0. 本鑑定が採る立場（案・未確定）

姓名判断に中立の正解はない。**画数の数え方も、何を見るかも、すべて流派による選択**である
（`2026-08-15_姓名判断の流派共通性リサーチ.md`）。

そこで、**普遍の真理として書くのをやめ、選択として宣言する。**
鑑定文にも「本鑑定はこの流儀で見ています」と明記し、他の流儀では違う結果になることを添える。

> **この節はまだ案。** 印のある項目は未決。人の判断を待っている。

### 採るもの

| 項目 | 選択 | 理由 |
|---|---|---|
| 画数 | **楷書体をそのまま数える。旧字体に直さない**（2026-08-15 決定） | **お客様が自分で数えて一致する。** 正字を特定する判断が要らず、間違いが一種類消える |
| 部首の数え方 | **見たままの画数**（さんずい＝3画）。本来の字に読み替えない | 上と同じ原則。阝は左右で区別しない |
| 漢数字 | **数の意味で数える**（十＝10） | 参照文献に漢数字の画数表があり、数の意味で数えていた（2026-08-15 訂正） |
| かな・英字 | **型に画数を持たない。人に上げる** | 素直な筆画数と一致しない値があるため、推測で埋めない |
| 新旧の併記 | **しない** | 使わない数字を見せると「どちらが正しいのか」を招く。**出品ページの記載は人が撤回する** |
| 五格 | **天格・人格・地格・外格・総格** | 全情報源で一致した共通土台 |
| 外格の出し方 | **総格 − 人格。例外を作らない** | 一字姓では「名の2文字目以降」になる。**姓も名も一字なら0になるので外格を見ない**（2節） |
| 天格 | **単独では吉凶を判断しない** | ほぼ共通と確認できた |
| 三才配置 | **天格・人格・地格の一の位を五行に置き換えて見る** | 別系統の文献でも同じ見方を確認。**共通土台として扱える**。外格と総格は三才に入れない |
| 成功運・基礎運 | **判定表を引かず、五行の相生・相剋の規則から導く** | 規則は広く共有されている。**特定の本の記述に依存しない**（4節） |
| 五行の見方 | **生む向き・抑える向き・同じ、の5区分で見る** | 参照文献は向きを見ず2区分。**5区分はこちらの選択**（4節） |

### 採らないもの

| 項目 | 判断 | 理由 |
|---|---|---|
| 主運・副運・前運・後運という呼称 | **使わない** | 1系統でしか確認できず、由来が特定できない。天格・人格などの名前で通す |
| 特定の流派名を掲げること | **名乗らない** | 制約のある流派の名称を商用で使わない |
| **性別で吉凶を変えること** | **採らない**（★下記） | 特定の画数を持つ女性に、結婚や死別についての不利益な断定を下すことになる。**文献の裏づけとは別の判断。** 詳細は3節 |
| 「相生」「相剋」「比和」という語 | **鑑定文に書かない** | 説明なしでは伝わらない（5-5）。「生む」「抑える」「同じ」で足りる |

### 採らないもの（続き・2026-08-15 確定）

| 項目 | 判断 | 理由 |
|---|---|---|
| **霊数（仮数）** | **使わない** | 参照文献の計算例に+1が出てこない。以前の規定は依拠替えの対象の書籍にしか出どころがなく、**お客様が検算できない**（2節） |
| **各格への年齢の割り当て** | **しない** | どの文献にも裏づけがない。**役割で書く**（2節） |
| **陰陽配列** | **採らない** | 片方の文献が明確に否定し、採る側でも画数と三才に従属して打ち消される（4-2） |
| **音（字音五行）** | **採らない** | 2冊目にしか無く、分量も足りない。**拡張の候補として控える**（4-3） |
| **性別・生き方で吉凶を変えること** | **採らない** | 特定の画数を持つ人に、結婚生活についての不利益な断定を下すことになる（3節） |

### すべて「宣言」である

上の5つは、**文献がそう決めているから採らないのではない。**
採る流儀も採らない流儀も実在する中で、**本鑑定がどちらを採るかを決めたもの**である。

だから0節の立場どおり、**普遍の正解としてではなく、選択として示す。**
反対の立場を採るなら、そのときに明示的に決め直す。

### 未決（★）

**残っているのは、判断ではなく確認の問題が一つだけ。**

| 項目 | 論点 |
|---|---|
| ★ **かな・英字の画数** | 参照文献に一覧はあるが、**素直な筆画数と一致しない値がある**。型に持たず、該当するお名前が来たら**人に上げる**（1節） |

### 鑑定文での書き方

選択したことは、**お客様にも明かす。**

- 「本鑑定は、書かれている字をそのまま数えています」と冒頭で述べる
- **性別によって判断を変えていない**ことを一言添える
- 「数え方の流儀は複数あり、旧字体で数える流儀では数字が変わります」と添える
- **数え方を説明する場面が、そのまま流儀の宣言になる**
- ただし**数字が違うことを、有料である理由にしない。** 価値は読み解きの側にある

隠して権威をまとうより、選んでいることを示すほうが、
これまで積み上げてきた「断定しない」「根拠を示す」姿勢と揃う。

## 1. 画数の数え方

**楷書体をそのまま数える。** お客様が実際に書いている字を、見たとおりに数える。
**旧字体に直さない。**（2026-08-15 決定。以前は旧字体で数えていた。経緯は末尾）

### 部首も見たまま数える

本来の字に読み替えない。

| 部首 | 画数 |
|---|---|
| 氵（さんずい） | 3 |
| 忄（りっしんべん） | 3 |
| 扌（てへん） | 3 |
| 犭（けものへん） | 3 |
| 艹（くさかんむり） | 3 |
| **辶（しんにょう）** | **4** ★ |
| 阝（左右とも） | 3 |
| 王（おうへん） | 4 |
| 礻（しめすへん） | 4 |
| 月（にくづき） | 4 |
| 衤（ころもへん） | 5 |

**阝は左右で区別しない。** 見た目が同じなので、同じ3画で数える。

**氵・犭・扌・ネ については、参照文献が明示している。**
「4画・5画とする流儀もあるが、そのまま素直に3画・4画と数える」と書かれていた。
**この4つは裏が取れている。**

**★辶だけは注意。** 見たまま数えれば3画だが、参照文献は難しい字の一覧で**4画**としている。
型はそれに合わせた。**人が本で再確認すること。**

忄・艹・王・月・衤は、参照文献に記述が見当たらなかった。見たままの画数を置いている。

### 活字の形に引きずられない

参照文献が注意している点。**印刷された活字は、手書きの楷書と形が違うことがある。**
「良」「衣」などは活字だとハネが「乚」に見えるため、そこを2画と数えてしまいやすい。

**画面に表示された字形ではなく、手書きの楷書として数える。**

### 旧字体には直さない

沢は7画。澤（16画）に直さない。斉は8画、竜は10画、辺は5画、桜は10画。
広は5画、国は8画、学は8画、体は7画、円は4画。

**戸籍の字体で書かれていれば、その字で数える。**
髙・﨑・邊のように、お客様が実際に使っている字がそれなら、その画数で数える。
**書かれている字を数える**という原則は、どちらの向きにも同じように働く。

### 漢数字は、数の意味で数える

**一=1、二=2、三=3、四=4、五=5、六=6、七=7、八=8、九=9、十=10**

> **2026-08-15 訂正。** 一度「書かれているものを数える」の原則から
> 十＝2画などと暫定で置いたが、**参照文献に漢数字の画数表があり、数の意味で数えていた。**
> 原則からの推測より、文献の記述を採る。**推測で埋めた箇所だった。**

### かな・英字の画数は、型に持たない

参照文献は、ひらがな・カタカナ・英字にも画数を与えている。
ただし**素直な筆画数とは一致しない値がある**（見たまま数えても同じにならない）。

**型にその一覧を持たない。写さないため、そして推測で埋めないため。**

**かなや英字を含むお名前が来たら、判断せずに人に上げる。**
人が文献を引いて画数を渡す。

### この数え方を選んだ理由

**お客様が自分で数えて、同じ数になる。**

- 「この字の正字は何か」という判断が要らない。書いてあるものを数えるだけ
- 判断が要らないぶん、**間違いが一種類まるごと消える**
- 検算できることは、「根拠を示す」「断定しない」という6節の姿勢と噛み合う

数字が他と違って見えることは、どちらを選んでも起きる。
旧字体で数える流儀は世に多いので、**違いの説明は必要**。
ただし**数字が違うことを、有料である理由にしない。** 価値は読み解きの側にある。

### 新旧の併記はしない（2026-08-15 変更）

以前は「新字体と画数が変わる字は両方を書く」としていた。**これをやめる。**

使わないほうの数字を見せると、「で、どちらが正しいのですか」を招くだけになる。
併記は数え方の透明性のためであって、選択肢を渡すためではない。
**採った数え方を一度説明すれば足りる。**

**出品ページの「新旧併記」の記載は、人が撤回する。**

### 廃止した規定（2026-08-15）

以前の型は**旧字体（正字）で数え、部首を本来の字の画数に読み替えていた**
（さんずい＝水4画、しんにょう＝辵7画など12項目）。漢数字は数の意味で数えていた。

やめた理由は3つ。

1. **正字を特定する判断が要り、そこが間違いの温床だった**
2. **お客様が検算できない**
3. 依拠替えで土台に置く文献が、楷書体をそのまま数える立場だった
   （`2026-08-15_田口二州流の方法メモ.md`）

**この変更で、ほとんどのお名前の数字が動く。** 珍しい字だけの話ではない。
納品済みの2件も、現在の基準とは合わなくなる。追いかけて訂正はしないが、記録に残す。

## 2. 五格の出し方（2026-08-15 確定）

**霊数（仮数）は使わない。** 書かれている字の画数だけで出す。

| 格 | 出し方 | 見るもの |
|---|---|---|
| 天格 | 姓の画数の合計 | 姓から受け継いだ土台。**単独では吉凶を判断しない**。人格との関係で働く |
| 人格 | 姓の最後の字＋名の最初の字 | **一生を通じた中心。** 性格もここで見る |
| 地格 | 名の画数の合計 | **足元。** 幼少期に形づくられ、生涯にわたって支える |
| 外格 | 総格 − 人格 | **人格に次いで重い。** 人格を外側から支える |
| 総格 | 全部の画数の合計 | **一生の運勢。** 全体を映す |

### 霊数（仮数）は採らない（2026-08-15 決定）

以前は「姓が一字、または名が一字なら、その空きに1を加える」としていた。**やめる。**

- **参照文献の計算例に、+1がどこにも出てこない。** 一字姓・一字名の例でも加算がない
- 以前の規定は、**依拠替えの対象である書籍にしか出どころがなかった**
- **お客様が検算できない。** 書いていない1画がどこから来たのか説明しづらい

**書かれている字だけを数える**という1節の原則と、これでそろった。

### 一字姓・一字名のときの外格

**外格は「総格 − 人格」で出す。例外を作らない。**

一字姓のとき、この式は「名の2文字目以降の合計」になる。

- 例：姓が一字、名が三字なら、外格は名の2文字目と3文字目の合計
- 例：姓が一字、名が二字なら、外格は名の2文字目の画数

**姓も名も一字のときは、外格が0になる。この場合は外格を見ない。**
五格の表に「—」と書き、本文でも触れない。**無理に数を立てない。**

> **これはこちらの選択である。**（★）
> 参照文献は一字姓のときだけ別の出し方をしているように読めるが、
> **計算例どうしで式が一致せず、一義に読み取れなかった。**
> 推測で埋めるより、**全ての構成で同じ式を使う**ほうが、説明もできるし検算もできる。
> 詳細は `2026-08-15_田口二州流の方法メモ.md`。

### 各格の呼び名は使わない

以前の型は、人格・外格・地格・総格に**主運・副運・前運・後運**という別名を併記していた。
**0節で「使わない」と決めたため、表から外した。**

由来が特定できる情報源が一つしかなく、**特定の流派の呼称**である可能性が高い。
天格・人格・地格・外格・総格という一般的な名前で通す。**鑑定文にも別名を書かない。**

### 各格に年齢を割り当てない（2026-08-15 決定）

以前は「地格は30代半ばごろまで」「総格はそこから」と、時期を区切っていた。**やめる。**

- **どの文献にも明確な裏づけが見つからなかった。** 資料間の食い違いが大きい
- 参照文献は総格を**一生の運勢**としており、後半生に限定していない

## 4. 三才配置（2026-08-15 組み直し）

**天格・人格・地格の3つを五行に置き換えて、その関係を見る。**
外格と総格は三才に入れない。

### 手順

**1. 各格の一の位を取る。** 十の位は落とす。11も21も31も、1として扱う。

**2. 一の位を五行に置き換える。**

| 一の位 | 五行 |
|---|---|
| 1・2 | 木 |
| 3・4 | 火 |
| 5・6 | 土 |
| 7・8 | 金 |
| 9・0 | 水 |

**この対応は参照文献と一致している。**（2026-08-15 確認）

**3. 二つの格の関係を見る。**

- **成功運** ＝ 天格と人格の関係（上が天格、下が人格）
- **基礎運** ＝ 人格と地格の関係（上が人格、下が地格）

### 五行の関係

木・火・土・金・水のあいだには、**生む向き**と**抑える向き**がある。

- **生む（相生）**：木 → 火 → 土 → 金 → 水 → 木
- **抑える（相剋）**：木 → 土 → 水 → 火 → 金 → 木
- **同じ（比和）**：五行が同じとき

この二つの並びは、姓名判断に固有のものではない。**広く共有された枠組み**である。
だから型は、判定表を持たずに**規則から導く。**

### ★向きを見るのは、こちらの選択（2026-08-15）

**参照文献は、向きを見ていない。**

その文献は、木火土金水の輪の中で**隣り合っていれば調和、隣り合っていなければ不調和**
という見方をしている。同じ五行も調和に入れる。**つまり2区分で、向きを問わない。**

型はこれに対し、**生む向き・抑える向き・同じ、の5区分で見る。**
向きを見る形は、相生・相剋の本来の姿ではあるが、**参照文献の扱いとは違う。**

**採る理由**：2区分だと、五格の組み合わせがどうであれ読みが2種類しか出ない。
それでは一件ずつ書く鑑定にならない（5-6の使い回し禁止と衝突する）。

**この5区分は、こちらの選択として宣言する。** 0節の宣言に含める。

### 関係の早見表

**上の格の五行を縦、下の格の五行を横に見る。**

| 上 ＼ 下 | 木 | 火 | 土 | 金 | 水 |
|---|---|---|---|---|---|
| **木** | 比和 | 上が生む | 上が抑える | 下が抑える | 下が生む |
| **火** | 下が生む | 比和 | 上が生む | 上が抑える | 下が抑える |
| **土** | 下が抑える | 下が生む | 比和 | 上が生む | 上が抑える |
| **金** | 上が抑える | 下が抑える | 下が生む | 比和 | 上が生む |
| **水** | 上が生む | 上が抑える | 下が抑える | 下が生む | 比和 |

**どの行にも5つの関係が一つずつ出る。** 表を覚える必要はなく、上の2本の並びから導ける。

### 成功運の読み方（天格と人格）

天格は姓から受け継いだ土台、人格は本人の中心。**上から下への働きとして見る。**

| 関係 | 読みの方向 |
|---|---|
| **上が生む** | 受け継いだものが本人を後押しする。伸びるときの抵抗が少なく、周りの助けを得やすい |
| **比和** | 土台と本人が同じ質。力がまっすぐ通る。**そのぶん外からの刺激が入りにくく、同じやり方を続けやすい** |
| **下が生む** | 本人が土台を支える側にまわる。周りに尽くす形で認められるが、**自分の分を後回しにしやすい** |
| **上が抑える** | 上からの制約を受けやすく、思うように進めない場面が出る。**時間はかかるが、抑えが外れると動きが大きい** |
| **下が抑える** | 受け継いだものに逆らう形で進む。摩擦は出るが、**自分で道を開く力**として働く |

### 基礎運の読み方（人格と地格）

人格が本人の中心、地格が足元。**足元がどう働くかとして見る。**

> **この読みの方向は、こちらの選択である。**（2026-08-15 記）
> 別系統の文献は、同じ五行の関係に**独自の重みづけ**をしていて、
> **比和でも良くないとする組がある**（水どうしなど）。
> 相生・相剋・比和という規則は共有されているが、**それをどう評価するかは流儀による。**
> だから4節は、関係ごとに**吉凶の判定を与えない。** 読みの方向を示すだけにとどめる。
> 「一般にそうなっている」と書かない。0節の宣言の対象に含める。

| 関係 | 読みの方向 |
|---|---|
| **下が生む** | 足元が厚く、下から押し上げる。**安定しやすい形** |
| **比和** | 本人と足元が同じ質。動きは少ない。**行き詰まったときに別の手が出にくい** |
| **上が生む** | 本人が足元を作っていく形。若いうちは負担が大きいが、**育てたものが後で効く** |
| **上が抑える** | 足元を削りながら進む形。**無理が続くと消耗する。休み方を持っておきたい** |
| **下が抑える** | 足元が揺れやすい。**土台を固める工夫がいる**。固まれば動きは速い |

### 書くときの決まり

- **「相生」「相剋」「比和」という語をそのまま鑑定文に書かない。** 5-5の専門用語の項に従う。
  「生む」「抑える」「同じ」で足りる
- **★ただし、まとまりの中身は必ず示す。**（2026-08-15 追加）
  禁じているのは**語**であって、**組み分けを見せないこと**ではない。

### まとまりの示し方（本文に必ず入れる）

初回テストで、**「一の位で五つの組に振り分けて」と書いたきり、
組が何なのかを一度も示さない**鑑定文が出た。チェック担当と初見のお客様が、
独立に同じ箇所を挙げている。

> 冒頭であれだけ「ご自身で数え直していただけるように」と言ってくれたのに、
> **いちばん結論に効く部分だけ手順が伏せられている。**
> ここだけ「信じてください」になっていて、前半の誠実さと噛み合っていない。

**楷書体をそのまま数える形にした理由（お客様が検算できること）が、
後半で自分から崩れる。** これを許さない。

**本文に、次の2つを平たい言葉で示す。**

1. **どの一の位が同じまとまりに入るか**（1と2／3と4／5と6／7と8／9と0）
2. **まとまりに並び順があり、隣り合えば後押しし、離れれば抑え合うこと**

表で示してよい（表は字数に数えない）。**五行の名前は使わない。**
これだけあれば、読者は自分の数がどこに入るかを確かめられる。

- **なぜ一の位で見るのかを、本文に一度示す。** 手順だけ書くと「決まりだから」に聞こえる
  （5-5に実際の声がある）
- 読みの方向は**出発点**であって、結論ではない。**そのお客様の話に着地させる**
- 表の言い回しをそのまま並べない。**同じ関係の別のお客様と同じ文になったら、書き直す**（5-6）

### 吉数が揃うことと、それが伸びることは別

**四つの格に吉数が揃っていても、それだけでは足りない。**
三才の配置によって、その吉数が伸びるか抑えられるかが変わる。

「吉数が揃っている」を結論にしない。それは出発点にすぎない。

| 7 | 強みが出る場面 | 200字 | 180〜220 |
| 8 | 気をつける場面 | 170字 | 153〜187 |
| 9 | まとめ（**具体的な提案を2つ以上**含む） | 140字 | 126〜154 |

合計およそ2,050字。

### ★2026-08-15 に構成を組み替えた

**以前は「人格の段落」「地格の段落」「外格の段落」「総格の段落」と、格ごとに1段落ずつ置いていた。**
初回テストで、**4段落とも同じ骨格になり、どのお名前でも成り立つ文章**になった。

原因は書き手ではなく、**型の側にあった。**

- 3節で「各数の解説を型に持たない」と決めた
- そのため各格の段落で使える材料が、**「吉か凶か」＋「その格の役割」しか残らない**
- 役割はどのお客様でも同じなので、**格ごとに1段落置くと、必ず同じ文になる**

**型が、自分で供給していない根拠を要求していた。**

### 実際に変わるものを軸にする

**個々の数の意味は読まない。** 型が供給できるのは次の3つだけで、書けるのもこの範囲である。

| 材料 | 何通りあるか |
|---|---|
| 4つの格（人格・地格・外格・総格）が、吉・凶・相半ばのどれか | 多い |
| **成功運**（天格と人格の関係） | 5通り |
| **基礎運**（人格と地格の関係） | 5通り |

**「15だから◯◯」ではなく、「この並びだから◯◯」で書く。**

とくに段落6が要になる。**二つの関係が同じ方向を向いているのか、打ち消し合うのか。**
ここは25通りあり、**お名前ごとに必ず違う。** 固有性は主にここから出す。

段落7・8は、段落4〜6から**そのお客様の場面に落とす**ところ。
一般論ではなく、上で出した関係から導く。

**成功運と基礎運は段落を分ける。** 一段落に詰めると二テーマ同居になり、
「読むのがしんどい」「途中で目が滑った」と言われた箇所になる。

**書き終えたら、各段落が許容幅に収まっているか、そして合計が帯に入っているかを見直す。**

### 少なすぎても、多すぎても型どおりではない

**合計は 1,800〜2,300字 に収める。**（「2,000字前後」の許容幅）
各段落は目安の**±10%**まで。

### ★段落の許容幅を全部使うと、合計が帯を超える

**以前はここが矛盾していた。** いまは解消してあるが、考え方として残す。

| | 字数 |
|---|---|
| 段落の目安の合計 | 2,050 |
| 全段落を許容幅の上限に寄せた合計 | 2,255（帯の内側） |
| 全段落を許容幅の下限に寄せた合計 | 1,845（帯の内側） |
| 帯 | 1,800〜2,300 |

> **2026-08-15 に許容幅を ±20% から ±10% に絞った。**
> 以前は上限に寄せると2,530字となり、**全段落が許容幅に収まっていても帯を超えた。**
> 初回テストで実際にそうなった（合計2,338字）。
> **いまは、どちらに寄せても帯の内側に収まる。** 算数の矛盾そのものを消した。

**合計の帯が優先する。** 段落の許容幅は**逃げ幅であって、目標ではない。**

- 基本は**目安に寄せて書く。** 許容幅は、内容の都合でどうしても動くときに使う
- **上限側に寄せてよいのは2〜3段落まで。** そのぶん他の段落を目安より短くして相殺する
- **「全段落が許容幅に収まっているから合格」ではない。** 合計を必ず確かめる

**実際に起きた失敗（2026-08-15、組み直し後の初回テスト）**

9段落すべてが許容幅に収まっていたのに、**合計2,338字で帯を38字超過**した。
各段落が上限寄りに書かれていたため。**段落ごとの判定だけでは超過を検出できない。**

- **足りないとき**：短い段落を書き足す。字数を稼ぐための水増しはしない
- **超えたとき**：長い段落から削る。削る順番は次のとおり

  1. 同じ内容を別の言い方で繰り返している文
  2. 画数の一般的な意味の説明（どのお客様にも当てはまる部分）
  3. そのお名前固有の読み解き ← **ここは最後まで残す**

過去の失敗例（どちらも同じお名前でのテスト）：

| 回 | 実測 | 内容 |
|---|---|---|
| 1回目 | 1,328字 | 3割強の不足。なのに「約1,950字」と自己申告していた |
| 2回目 | 2,592字 | 3割の超過。8段落すべてが目安を上回り、三才・陰陽が429字（目安300字） |

**不足を直そうとして超過に振れた。** 下限と上限は必ずセットで見る。

### 最終確認は人がする

実際の字数の確認は、鑑定担当ではなく**人が行う**。
「確認してほしい点」に、字数を確認してほしい旨を毎回書く。
そのとき、**不足していた場合に書き足せる段落と、超過していた場合に削れる段落の両方**を挙げておく。

## 5-3. 表記のルール

お客様が受け取って読むものなので、**見た目を毎回そろえる**。
一件ずつ書く商品だが、体裁まで毎回変わってよいわけではない。

### 数字

**画数・五格の数値は、表も本文も算用数字で統一する。**

| 種類 | 表記 | 例 |
|---|---|---|
| 鑑定上の数値（画数・五格） | **算用数字** | 「人格は15」「合わせて12画」 |
| 普通の和文数詞 | 漢数字 | 「四字とも」「一つも」「二層の構え」 |

#### なぜ揃えるか

以前は「表は算用数字、本文は漢数字」と定めていた。社内では整って見えたが、
初見のお客様に読んでもらったところ、こう返ってきた。

> 表は「人格 15」、本文は「人格は十五」。表と本文を見比べようとしたときに、
> いちいち頭の中で変換が必要で、少し面倒だった。

**読み手は表と本文を行き来する。** 同じ数が違う形で書いてあると、そのたびに変換がいる。
文章としての読みやすさより、照合のしやすさを優先する。

### 敬称と宛名

- 敬称は**「様」**に統一する（「さま」「さん」は使わない）
- 鑑定文本体は、**冒頭に「〇〇様」の宛名を置いてから**書き始める
- **本文中でお名前を呼ぶのは、宛名を除いて1〜2回。** 0回でも3回以上でもいけない

#### 上限と下限の両方がある理由

回数を二度とも外している。上限だけ決めて、次は下限側に振れた。

**多すぎたとき**（本文に7回以上）——

> 差し込み印刷のように見えてしまう瞬間があった。一段落に一回、決まった位置に
> 規則的に出てくるので、テンプレートの穴埋めを連想した。

**そこで「多くて2回まで」と上限だけ定めた。すると次は0回になった**——

> 名前の分析結果を見せてもらっているのであって、**自分に向けて書かれた手紙という
> 感じはしなかった。** 同じ画数構成の別人に、そのまま送っても成立する文章だと思う。

丁寧にしようと繰り返せば機械に見え、避ければ他人行儀になる。**1〜2回。**

**片側だけの制限を書かない。** 字数のときも同じ失敗をしている（下限だけ定めて超過に振れた）。
数を制限するルールを足すときは、必ず上限と下限をセットで書く。

### なぜ決めておくか

過去3回のテストで、同じお名前なのに毎回体裁が変わった。

| 回 | 本文の数字 | 敬称 | 冒頭の宛名 |
|---|---|---|---|
| 1回目 | 算用数字 | さま | あり |
| 2回目 | 算用数字 | さま | あり（見出し形式） |
| 3回目 | 漢数字 | 様 | **なし** |

内容が正しくても、体裁が毎回違えば商品として不揃いになる。
上のルールに合わせる。

## 5-4. お客様に渡すもの

**トークルームに貼るのは、次の順で。**

1. 宛名（〇〇様）
2. **挨拶と、数え方の説明**（導入の段落）
3. 画数の内訳の表
4. 五格の表（格の名前・計算・数だけ。**吉凶欄は入れない**）
5. 鑑定文本文
6. 免責文

成功運・基礎運は**表にせず、本文の中で説明する。**
候補比較の表は、候補が複数のときだけ加える。

### 表は置く。ただし本文で数字を並べ直さない

ここは一度、逆に決めて戻している。経緯を残す。

**最初**：五格も表にしていた。初見のお客様から——

> 知りたいのは結果なので、表を三つ飛ばして本文から読んだ。
> 表の情報は本文にほぼ全部書き直されているので、結果的に同じ内容を二回読んだ。

**そこで五格の表をやめ、本文で説明する形にした。** すると別のお客様から——

> ここで一回止まった。三回読み直した。初めて聞く言葉が五つ、初めて聞く計算方法が五つ、
> 数字が五つ、全部が一文に入っている。**表になっていれば一目なのに。**
> ここが一番の関門で、ここで読むのをやめる人はいると思う。

**不満だったのは表ではなく、表と本文の重複だった。** だから表は戻し、重複のほうを断つ。

- 五格の**名前・計算・数**は表に置く
- **本文では、五つの数を並べ直さない。** 各格の段落で必要な数にだけ触れる
- 五格全体を扱う段落は、数の列挙ではなく**並びとしての読み**を書く。
  **使えるのは「どこが吉で、どこが違うか」だけ。**「17は前に出る数」のような
  **個々の数の性質は、型が供給していないので書けない**（5-2の組み替えを参照）

### 五格の表に吉凶欄を入れない

お客様に渡す表は、数え方を確認するためのもの。
吉凶を一覧にすると、そこだけが読まれて本文が読まれなくなる。
吉凶は本文で、理由とともに書く。天格の「—」問題もここで消える。

### 挨拶より先に表を置かない

> 開いた瞬間に表が出てきて、事務書類が届いたかと思った。

宛名のすぐ下は挨拶と数え方の説明。表はそのあと。
「該当なし」の備考（霊数など）も、数え方の説明が済んだあとの表に付ける。

### 社内確認用の出力は別

鑑定担当が出す「五格の表」「成功運・基礎運の判定」「確認してほしい点」は、
**人が点検するための出力**であって、お客様に渡すものではない。混ぜない。

## 5-5. 読み手がつまずくところ

初見のお客様に読んでもらって分かった、避けるべき書き方。

### 専門用語を説明なしに使わない

説明がないまま出てきて、意味が取れなかったと言われた言葉：
**霊数（仮数）／三才／成功運／基礎運／吉数**
（かつては「熊崎式」「正字」も挙がっていたが、いずれも使わなくなった）

- **初出で、一言だけ添える。** 長い解説はいらない
- 添えられない用語は、**使わずに書く**
- 特に**一の位で組に分ける手順**は、なぜそうするのかが伝わりにくい。
  「十の位を落として、残った数で見る」ことを本文に一度示す

以前、五行への変換を使っていたときは、こう言われた。

> 7だから金、5だから土。なぜその対応なのかが最後まで分からず、
> 「決まりだから」と言われている気持ちになった。

**手順を書くだけでは足りない。なぜそう見るのかを一言添える。**

### 「該当なし」を並べない

「併記の必要はありません」「霊数の加算はなし」「特殊カウントに該当する字はありません」
「相剋の組み合わせなし」——**無いものの列挙が続くと、中身の薄い書類に見える。**

該当しない項目は**表の備考に一行**で置き、本文で並べない。

### 空振りする説明をしない

以前、旧字体で数えていたころ、新旧で画数が変わらないお名前に対して
「無料サイトとは数え方が違います」を長く説明してから「今回は同じ数字です」と
続けてしまい、肩透かしになった。

> 「うちは無料サイトと違う」と言われた直後に「今回は同じです」と言われたので、
> じゃあ何が違うのかと思った。

**楷書体をそのまま数える形にしたので、この失敗はもっと起きやすくなった。**（2026-08-15 記）
無料の判断ツールと**同じ数字になることのほうが多い**。

だから、**数字の違いを売りにしない。**

- 数え方は「本鑑定はこう数えています」と一度示すだけでよい。長く語らない
- 「他とは違う」と書かない。**違わないことのほうが多い**
- 数字が違って見えるお客様（旧字体で見てもらった経験のある方）には、
  「旧字体で数える流儀もあり、そちらでは数字が変わります」と一文添えれば足りる

**価値は読み解きの側にある。** 数字が同じであることは、むしろ検算できるという強みになる。

**差が出ないお名前では、その説明は一文にとどめる。**

### 同じ指摘を三回書かない

弱点をひとつしか見つけられないと、それを人格・地格・まとめで繰り返すことになる。

> 三度目で「もう分かりました」と思った。しかも三回とも同じ内容で、深まっていない。
> 弱点の指摘がこれ一つしかないので、繰り返すと「他に言うことがないのかな」と見えてしまう。

同じモチーフは**多くて2回**。2回目は必ず別の角度から書く。

**これは弱点だけの話ではない。** 数の性質も同じ。
ある鑑定文では「決めたら方向を変えない」が人格・地格・総格・三才・まとめの**5箇所**に出た。
一段落の中で「押し通す／方針を変えない／話を聞かない／譲らない」と4回言い換えた箇所もあった。

> まとめに入ったとき「さっき読んだ」と思った。
> 短い鑑定文なのに繰り返しが多いのは、余計に短く感じる原因になっている。

**繰り返すと、分量まで少なく感じさせる。**

### 矛盾の解き方を毎回同じにしない

5-5の「矛盾を放置しない」を機械的に当てると、こうなる。

> 「両立しないが、両方を持ち合わせている」
> 「反対を向いているようだが、両立する」

同じ鑑定文の中で2回。読み手はこう受け取った。

> 二回目で「あ、この人はどっちに転んでも良い話にするんだな」と思ってしまった。
> 逆のことを言っているのに結論が両方プラス。一回目は納得したけど、**二回目で仕掛けに見えた。**

矛盾の扱い方は毎回変える。**そして、必ずしも両立させなくてよい。**
「この二つは同じ場面では出せない。どちらを出すかを選ぶことになる」と書ける場合もある。
**すべてを良い話に着地させると、読み手は型を見抜く。**

### 段落を、分類の結果で終わらせない

> 「土と金は生かし合う組み合わせで、向きとしては土が金を生かす側です。」
> **「で、それは私にとって何なんですか」と思った。** 分類作業を見せられただけで、
> 話が私に戻ってこなかった。

どの段落も、最後は**「だからあなたはこうなりやすい」**で終える。
用語の説明や分類の結果で切らない。特に成功運・基礎運の段落で起きやすい。

### 同じ材料しか持たない段落に、固有性を持たせる

材料が少ない段落は、使い回しになりやすい。**書けることが最初から同じ**になるからである。

実際、姓が同じで総格・地格・陰陽が一致する2名の鑑定文で、当時あった陰陽段落の主張が
**7項目すべて、順番まで一致**した（語句は書き換わっていたため、字面の照合では見つからなかった）。
他の段落は人格や外格を絡めて固有性を確保していたのに、その段落だけが単独で書かれていた。

陰陽は廃止したが、**同じことは成功運・基礎運でも起きる。**
組み合わせの判定は5組×5組しかないため、同じ組に入るお名前は同じ判定になる。

**判定をそのまま書いて終わらせない。** そのお名前の実際の数（15なのか25なのか）、
他の格との重なり方、時期の並びと結びつけて書く。判定は出発点であって、結論ではない。

### 根拠のない希少性を書かない

「これはそれほど多い並びではありません」のような頻度の主張は、裏付けがない。

> 珍しいと言われて嬉しい反面、どのくらい珍しいのか分からないので信じきれない。
> 十人に一人なのか、千人に一人なのか。数字を扱う鑑定なのに、ここだけ数字がない。

**数えられない希少性は書かない。**

### 矛盾を放置しない

複数の要素が反対を向くことがある（例：成功運は抑えられる配置だが、基礎運は堅い）。

> 勢いがあるのか、動き出しが遅いのか、どっちなんだろうと引っかかった。

どちらかを消すのではなく、**二つがどう共存するのかを一文で書く。**
「良し悪しではなく振れ幅の話です」のような断り書きは、矛盾の解消にならない。

### 時期の書き方（2026-08-15 全面差し替え）

以前ここには「**時期には年齢の目安を添える**」という項目があり、
「前運＝35〜36歳ごろまで、主運＝一生の中心、後運＝中年から晩年」と具体的な年齢を指示していた。

**この指示は廃止する。** 2節で各格への年齢の割り当てをやめ、0節で前運・主運・後運という
呼称を使わないと決めたため、**この節だけが逆のことを指示している状態になっていた。**

> **組み直し後の初回テストで、チェック担当がこの食い違いを見つけた。**（2026-08-15）
> 下書き自体は正しく2節に従っていたが、**次に書く人がここを読めば年齢を書いてしまう。**
> 節をまたいだ矛盾は、条項ごとの点検では出にくい。

**代わりの決まりはこうする。**

- **年齢を書かない。**「◯歳まで」「◯歳から」「中年期」は使わない
- もとの指摘（「自分が今どこにいるか分からない」）は、**年齢ではなく局面で答える。**
  「若いころ」「役割が変わったとき」「積んだものが効き始めてから」のように、
  **お客様が自分で当てはめられる言い方**にする
- **格を人生の段階に割り当てない。** 数字を消しても、
  「局面が変わるたびに」「流れが切れる」のような書き方をすれば、
  **五格が順番に人生に対応しているという前提が残る。** これも書かない

### 触れた話を放置しない

「姓が持つ7は、筋を通す硬質さを含んだ土台の数です」で終わると、

> これだけ？ 家系の話でも続くのかと期待して読み進めたら、そこで終わっていた。

**一文だけ出して回収しない話題を作らない。** 書くなら他の格と同じ厚みで書く。

### 初回テストで出たつまずき（2026-08-15 追加）

組み直し後の初回テストで、初見のお客様から新しく挙がったもの。

| どこ | 何が起きたか | 決まり |
|---|---|---|
| **後半に見出しがない** | 前半は表と太字の見出しがあるのに、本文に入ると長い段落が7つ続く。「どこまで進んだか分からない」 | **各段落に短い見出しを付ける。** 前半だけ整っていて後半が続き文だと、落差が目立つ |

### 読み終えて何をすればいいかを、一つは書く

全体が「あなたはこういう人です」で終わると、行動が変わらない。
まとめに、**具体的な提案をひとつ**、「ひとつの見方」として添える。

## 5-6. 型にない手順を使わない

**この型に書かれていない見方で、読みを作らない。**

**流派名は掲げないと決めた（0節）。だからこそ、型が唯一の拠りどころになる。**
名乗る流派が無い以上、「その流派ではこう見る」という言い訳が効かない。
型にない手順が混じれば、**その読みには何の裏づけも無いことになる。**

### 実際に起きた例

段落の中に、こう書かれた。

> この7は、五行という分け方では、対人面の外格8と同じ「金」にあたります。
> 受け継いだ土台と、外で見せる顔が同じ質でできている

- 7も8も一の位が金であること自体は、**4節の対応表どおりで正しい**
- しかし**三才配置は天格・人格・地格の3つで見るもの**で、外格を五行に含める規定は型にない
- つまり「正しい数字から出発した、根拠のない読み」

### なぜ見落とされたか

数字が合っているため、点検を素通りした。
チェック担当は「計算が一致するか」と「型の条項に反していないか」を見ていたが、
**型に書かれていないことをしていないか**は見ていなかった。

**禁止事項に載っていない ≠ やってよい。** 型は、やってよいことを定めたもの。

### 画数の「大小」を量として読まない

2件目に見つかった同じ形の逸脱。

> この6は、五つの数のなかでいちばん小さい数です。総格は23、人格は17と、内側には
> 大きな数が並んでいるのに、外へ向かう窓にあたる部分だけが6にとどまっています。
> 持っているものの総量に対して、外に出す量が少なめ、と読めます

**画数の大小がエネルギーの量を表す、という規定は型にない。**
型が各格について定めているのは「見るもの」と「吉凶」だけ。6は立派な吉数であり、
23より小さいことに意味はない。

#### 性質を比べるのは可、大きさを比べるのは不可

この線引きは細かいので、例で示す。

| 書き方 | 判定 |
|---|---|
| 「四つの中で総格だけが相半ばの数」 | **可**。型が持っている**区分**を比べている |
| 「人格は吉数だが、地格との関係は抑え合う向き」 | **可**。区分と、三才の関係を組み合わせている |
| 「穏やかな15・16に対して、23は外へ広がる数」 | **不可**（2026-08-15 変更）。**個々の数の性質は型が供給していない** |
| 「17と23はどちらも前に出る数」 | **不可**。同上 |
| 「6は五つの中でいちばん小さいので、外に出す量が少ない」 | **不可**。数値の**大きさ**を量として扱っている |
| 「総格23は五つの中でもっとも大きいので運が強い」 | **不可**。同上 |

格どうしを突き合わせて読むこと自体は、固有性を出すために推奨される（5-5の否定形テスト）。
**比べてよいのは、型が各数に与えている性質。数字そのものの大小ではない。**

### 原典の言葉を写さない

**原典（熊﨑健翁『普及版 熊崎式姓名學』）の文章を、型にも鑑定文にも書き写さない。**

原典には、八十一数の解説について**転載を禁じる旨が明記されている**。
その意思を尊重する。守るのは、禁じられているからというより、そうすべきだからである。

受け取るのは、**教えと考え方、そして事実**。

| 受け取るもの | 書き方 |
|---|---|
| 各数が吉か凶か、相半ばか | **事実として型に記す** |
| 女性で判断が変わる数 | 同上 |
| 画数の数え方、五格の出し方 | 同上 |
| 数が示す性質・傾向の内容 | **理解して、自分の言葉で書く** |
| 原典の文章そのもの | **書かない** |

### 言い換えのときに、趣旨を曲げない

ここが一番むずかしい。**自分の言葉に置き換えることと、意味を変えることは違う。**

言い換えているうちに、

- 原典が「凶」としている数を、やわらかく言い直して吉のように読ませる
- 原典が条件付きで述べていることを、条件を落として断定する
- 原典にない要素を、言い換えのついでに足す

これらはすべて、**原典の言葉を写さない代わりに、原典の趣旨を裏切っている。**
写さないことと、離れてよいことは別である。

**迷ったら、意味を保つほうを取る。** 表現の新しさより、趣旨の正確さが先。

### 参照した文献すべてに、同じ規律を適用する（2026-08-15 拡張）

上の「原典の言葉を写さない」は、はじめ熊崎式の書籍1冊だけを想定して書いた。
**依拠替えで参照する文献が増えたので、対象を全文献に広げる。**

参照した本には、いずれも**転載・複製・頒布・公衆送信・翻訳・翻案を禁じる旨**が
奥付に書かれている。これは占いの本に限らず、ほとんどの本にある通常の表示である。
それでも、**鑑定文はお客様に渡す商品**なので、線引きをはっきりさせておく。

#### 使ってよいもの、いけないもの

| | 扱い | 理由 |
|---|---|---|
| 画数の数え方、格の出し方、何と何を突き合わせるか | **使える** | 手順であって文章ではない |
| ある数を吉とするか凶とするか | **使える** | その体系がそう定めているという事実 |
| 相生相剋のような、広く共有された枠組み | **使える** | 特定の本の持ち物ではない |
| 個々の字の画数 | **使える** | 事実。ただし**一覧を丸ごと持ってこない**（下記） |
| 各数の解説文、例文、たとえ話、言い回し | **書き写さない** | 文章そのもの |
| 解説文を文単位で言い換えたもの | **書かない** | 順番も筋も元のままなら、なぞっているのと変わらない |
| 一覧表・分類表を、そのまま並べ直したもの | **作らない** | 何をどう並べたかにも作り手の判断が入っている |

**とくに注意すべきは、下から2番目。**
言葉を入れ替えただけの文は「自分の言葉で書いた」ことにならない。
奥付が禁じているのは複写だけでなく、**作り替えて使うこと**も含んでいる。

#### だから、こう書く

**元の文章を手元に置いて言い換えるのではなく、お名前から書き起こす。**

1. 手順に従って、そのお客様の画数と各格を出す
2. その数の組み合わせが**このお客様にとってどういうことか**を考える
3. **そこから文章を書く。** 元の解説文は参照しない

この順番なら、出てくる文章はそのお客様固有のものになる。
**同じ数を持つ別のお客様と同じ文章になったら、それは手順を飛ばした証拠。**
5-6の「使い回しをしない」と、ここは同じことを別の角度から言っている。

#### 漢字の画数一覧について

事典型の本には、画数別・読み方別の漢字一覧がある。**引くのは自由。**
ただし**一覧そのものを写してファイルに置かない。** 必要な字を、必要なときに引く。

#### 型に書き写さないのも同じ理由

この規律は鑑定文だけでなく、**この型ファイルにも適用する。**
型は社内文書だが、リポジトリに残り、鑑定文の元になる。
ここに解説文を写せば、鑑定文に流れ出る。

### 迷ったときは

型にない見方を使いたくなったら、その場で使わずに**人に上げる**。
裏付けのある流派の手法なら、調べたうえで型に追記してから使う。
**型を自分に都合よく広げない。**

これまでに2件とも、**数字は正しいのに読みに根拠がない**という形だった。
計算が合っていることは、その読みが型に沿っている保証にならない。
