# 動画プロンプトの型

日次5件から、縦型10秒のショート動画を作るための型。
**1件ごとに素材シートを1枚作り、そこから各ツールの形に流し込む。**

素材シートを間に挟むのは、ツールを乗り換えても原稿を作り直さずに済むようにするため。

```
日次5件 ──→ 素材シート（1件1枚） ──┬─→ アバター型（読み上げ）
                                  ├─→ 映像音声一括型（映画的）
                                  └─→ 映像のみ型（無音・音は後乗せ）
                                        │
                                        └─→ 投稿文（キャプション・ハッシュタグ）
```

## 本数の決めかた

| 型 | 中身 | 使いどころ |
|---|---|---|
| **型A：1件1本** | 1件を10秒で掘る。1日5本 | 本命。毎日これを回す |
| **型B：5件まとめ1本** | 5件を10秒に詰める。テロップのみ | 週のまとめ、フォロワー向けの目次 |

**10秒に5件を読み上げで入れるのは無理。** 1件あたり2秒しかない。
型Bは音声をあきらめて、テロップと効果音で流す。

## 尺と字数

日本語のナレーションは、ショート動画の速さで**1秒あたり約7字**。
10秒の実尺は、頭と尻の余白を引いて9秒。**本文は60〜70字が上限**。

これを超えた原稿は、必ず早口になるか、尻切れになる。**書き直す。**

### 型Aの秒割り

| 秒 | 役割 | 字数の目安 |
|---|---|---|
| 0.0〜1.5 | フック。数字か一言で止める | 10〜14字 |
| 1.5〜6.5 | 何が起きたか。いつ・誰が・何を | 30〜35字 |
| 6.5〜8.5 | なぜ効くか。読み手に何が変わるか | 12〜16字 |
| 8.5〜10.0 | 締め。出典の明示とフォロー誘導 | 8〜10字 |

**フックに煽りを置かない。** 数字そのものが一番強い。
「1億ドル」「630ページ」「126か所」のような、確認できる数字で止める。

### 型Bの秒割り

| 秒 | 中身 |
|---|---|
| 0.0〜1.0 | 日付と「今日の5件」 |
| 1.0〜8.5 | 5件を1.5秒ずつ。1件は**全角12字以内**のテロップ1行 |
| 8.5〜10.0 | 「出典は説明欄」＋フォロー誘導 |

## 素材シート（1件1枚）

```
【素材シート】YYYY-MM-DD ／ 第n件
見出し   ：（全角20字以内）
発表元   ：
発表日   ：
出典URL  ：
事実     ：（発表文から写した数字と固有名詞。3行以内）
なぜ効くか：（1行）
キーの数字：（映像に出す数字を1つだけ選ぶ）
画の方向 ：（下の「画の引き出し」から1つ）
避けるもの：（この件で映してはいけないもの）
```

### 画の引き出し

値上がりを示唆する画を使わない（部門ルール）。代わりにこの中から選ぶ。

| 話の種類 | 画 |
|---|---|
| 規制・法案 | 議事堂の外観、書類の束、押される印、開く扉 |
| 当局の規則 | 官報のページ、締切のカレンダー、印刷機 |
| 中央銀行 | 会議室の空席、マイク、時計の針 |
| 提携・出資 | 握手ではなく、2つの建物を結ぶ光の線、配線 |
| プロトコル技術 | 抽象的な格子、データの流れ、組み替わるブロック |
| 資金の流れ | 太さの違う2本の流れ、天秤 |

**チャートを映さない。** 値動きの画は投資助言に見える。

# ツール別の型

## 共通の前提

- 画面比 **9:16**（1080×1920）、尺 **10秒**
- **日本語のテロップを生成させない。** どのツールも日本語の文字は崩れる。
  文字は動画を書き出してから編集で乗せる。プロンプトでは「文字を入れない」と指定する
- 実在の人物の顔、企業のロゴ、取引所の画面を再現させない
- 音楽は権利のはっきりしたものを使う。ツールが生成した音楽も、投稿先の規約を確認する

## 型1：アバター型（読み上げ系のツール）

アバターが台本を喋る形式。**台本がそのまま成果物になる**ので、字数の管理が効く。

```
■ 台本（そのまま読み上げさせる。60〜70字）
（素材シートの フック＋事実＋なぜ効くか＋締め をつないだ1本の文章）

■ アバター
性別・年齢感：（例：30代前半、落ち着いた声）
服装：ジャケット。無地。ロゴなし
姿勢：正面。上半身。身振りは小さく

■ 声
言語：日本語
速度：やや速め（1秒あたり7字で10秒に収まること）
トーン：断定しすぎない、報道寄り

■ 画面
比率：9:16
背景：（素材シートの「画の方向」。単色か、ごく浅いぼけ）
アバターの位置：画面の下3分の1。上3分の2はテロップ用に空ける
字幕：**生成しない**（後乗せするため）

■ 避けるもの
チャート、通貨記号、札束、上向きの矢印、実在のロゴ、実在の人物
```

**上3分の2を空けるのが肝。** ここに後から見出しと数字を乗せる。
アバターを真ん中に置くと、テロップの置き場がなくなる。

## 型2：映像音声一括型（映像と音を一度に作る系のツール）

1段落の記述で映像と音を同時に決める。**箇条書きより、つながった文章のほうが効く。**

```
■ プロンプト（英語で書く。1段落）
A vertical 9:16, 10-second shot. 
[被写体と場面]. 
[被写体の動き]. 
Camera: [カメラの動き。例：slow push-in / static locked-off / slow orbit]. 
Lens: [例：35mm, shallow depth of field]. 
Lighting: [例：cool overcast daylight / single hard key from the left]. 
Color: [例：desaturated blue-grey with one warm accent]. 
Texture: [例：subtle film grain, no motion blur]. 
Audio: [環境音と効果音]. A calm Japanese male voice narrates: "[台本60〜70字をそのまま]". 
No on-screen text, no captions, no logos, no charts, no currency symbols, no real people.

■ ネガティブ
text, captions, subtitles, watermark, logo, chart, graph, arrow, 
banknotes, coins, luxury goods, celebrity likeness, distorted hands
```

- **カメラは1回の動きに絞る。** 10秒で寄って引いて回すと、何も見えない
- 場面転換を入れない。**10秒は1カット**が最も安定する
- ナレーションはプロンプトの中に台本をそのまま埋める。要約させない

## 型3：映像のみ型（短い映像に特化した系のツール）

映像だけを作り、音は後で乗せる。**1文が短いほど安定する。**

```
■ 映像プロンプト（1〜2文）
（例：Slow push-in on a stack of thick printed documents on a dark wooden desk, 
single window light from the left, cool grey tones, shallow depth of field.）

■ カメラ指定
（push in / pull out / pan left / pan right / static のいずれか1つ）

■ 尺・比率
10秒 / 9:16

■ ネガティブ
text, logo, chart, people, arrows, watermark

■ 後で乗せるもの（編集で）
・ナレーション音声（台本60〜70字を読み上げ）
・テロップ（見出し全角20字以内 ＋ キーの数字）
・出典（画面の下に小さく、発表元の名前）
・BGM（権利の確認済みのもの）
```

この型は工程が1つ増えるが、**映像の質は一番安定する**。
迷ったらこれにする。

# 投稿文の型

## Instagram（リール）

```
（1行目：フック。動画のフックと同じ文言にしない。言い換える）

（空行）
・（事実1）
・（事実2）
・（なぜ効くか）

出典：（発表元の名前）（発表日）
（URL）

※この投稿は事実の紹介です。投資の助言ではありません。

（ハッシュタグ 10〜15個。日本語と英語を混ぜる）
```

- 1行目は**スクロールを止める役**。全角25字以内
- 出典URLは本文に置く。リールの説明文はリンクにならないが、**出したという事実が効く**
- 免責は毎回入れる。省かない

## TikTok

```
（1行。全角30字以内。フックをそのまま）
出典は固定コメント欄
#（ハッシュタグ 4〜6個）
```

- TikTokの説明文は短く。**長いと読まれない**
- 出典URLは投稿後に自分でコメントして固定する
- オンスクリーンテキスト（動画に焼いた文字）は、見出しとキーの数字の**2つだけ**

## ハッシュタグの決めかた

| 層 | 数 | 例 |
|---|---|---|
| 広い層 | 2〜3 | 暗号資産、仮想通貨 |
| 話題の層 | 3〜5 | その件の固有名詞（法案名、企業名、プロトコル名） |
| 形式の層 | 2〜3 | 毎日更新、ニュース、1分解説 |
| 英語 | 3〜4 | 海外の一次情報を扱っているため |

**毎回同じ組み合わせを貼らない。** 話題の層は件ごとに入れ替える。

# 出す前の確認

動画とキャプションができたら、人に渡す前にこれを通す。

- [ ] 台本は60〜70字か。読み上げて10秒に収まったか（**実測する**）
- [ ] 数字は発表文のとおりか。丸めていないか
- [ ] 発表日を書いたか。記事の日付を書いていないか
- [ ] 決まっていないことを、決まったように書いていないか
- [ ] 「買い」「上がる」「好機」の類が入っていないか
- [ ] チャート・札束・上向きの矢印が映っていないか
- [ ] 実在の人物の顔、企業のロゴが映っていないか
- [ ] 出典を画面か説明文のどちらかに出したか
- [ ] 免責を入れたか
- [ ] 日本語のテロップが崩れていないか（生成物に文字が混ざっていないか）

**字数と尺の実測は人がやる。** 推定値を書かない。
