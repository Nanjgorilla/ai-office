# 世界ニュース部門

## 担当領域

海外の一次情報から、その日世界で動いたことを毎日**5件**にまとめ、
**10秒の縦動画**を作るための台本とプロンプトまでを用意する。

読み手は「日々ニュースを見る時間があまり取れない日本の人」。
**この5件だけ見れば、その日の世界の動きが分かる**状態を目指す。

- 海外の一次情報の収集と裏取り
- 5件の選定、日本語への直し（背景の補い・単位と時刻の換算）
- 10秒動画の台本と、動画作成ツールに打ち込むプロンプトの作成
- 投稿用のキャプション案

引き受けないもの：動画の生成そのもの、投稿作業、相場や投資の助言、国内ニュースだけの解説。

## 依頼の受け方

依頼は必ず秘書経由（全社ルール4）。成果物ができたら秘書に渡し、日次ログに記録してもらう。

## 使う部品

| 部品 | 名前 | 役割 |
|---|---|---|
| サブエージェント | `news-researcher` | 海外の一次情報を拾いに行く係。読み取りと検索のみ |
| サブエージェント | `news-writer` | 材料から5件を選び、日本語の要約にする係。外部アクセスなし |
| サブエージェント | `news-checker` | 出所と数字を独立に裏取りする係。直さない |
| サブエージェント | `news-video-prompt` | 10秒動画の台本とプロンプトを書く係。外部アクセスなし |
| 参照ファイル | `departments/news/一次情報の型.md` | 何を一次情報と呼ぶか、どう裏取りするか、5件の選び方 |
| 参照ファイル | `departments/news/動画プロンプトの型.md` | 10秒動画の構成、台本の長さ、プロンプトの組み立て方 |

## 毎日の流れ

**裏取りを通してから人に渡す。** 拾ってきたものをそのまま要約にしない。

1. **収集担当**（`news-researcher`）が海外を当たり、候補を10件前後、出所つきで持ち帰る
2. **まとめ担当**（`news-writer`）が型に沿って5件を選び、日本語の要約を書く
3. **裏取り担当**（`news-checker`）が、要約を見る前に**出所を自分で当たり直す**
4. **動画担当**（`news-video-prompt`）が台本とプロンプトを書く
5. 指摘を直し、直したものと指摘の一覧をまとめて人に渡す。**出すかどうかを決めるのは人**

3 と 4 は同時に走らせてよい。

### 裏取り担当への渡し方

**要約を見せる前に、主題と日付だけを渡して先に当たらせる。**

要約を先に読ませると、そこに書かれた数字が正解に見えてしまい、追認するだけの点検になる。
「合っていますか」と聞かない。**自分で出させてから、突き合わせる。**

これは鑑定のチェック担当（`departments/coconala/CLAUDE.md`）と同じ考え方で、
理由も同じ。ニュースでは数字（死者数・議席数・日付）がそのまま画面の文字になるため、
追認が一度でも通ると、そのまま動画に焼き込まれる。

### 読み上げの字数は人が数える

台本の字数は、動画の尺をそのまま決める。
まとめ担当にも動画担当にも字を数える道具を持たせていないので、**推定値を書かせない**。
実測は、道具を持っている側（秘書役か人）が行う。

## 成果物の置き方

- 保存先：`departments/news/`
- ファイル名：`YYYY-MM-DD_世界ニュース5件.md`
- 既存ファイルは上書きせず追記。同じ日付のファイルがあれば、そこに追記する（全社ルール2・3）
- 各件に**取得日時（日本時間）**を必ず書く。ニュースは半日で数字が変わる

## 迷ったときの判断

| 場面 | 判断 |
|---|---|
| 一次情報にたどり着けない | 二次情報のまま出さない。確度△として、何が確認できていないかを書く |
| 数字が媒体ごとに違う | 当局の発表値を採り、いつ時点かを添える。幅があるなら幅のまま書く |
| 続報で数字が変わった | 前の記録を書き換えない。その日のファイルに追記して更新する |
| 5件に収まらない | 次点として主題だけ残す。同じ主題で2枠は使わない |
| この部署の範囲か怪しい | `inbox/` に戻して秘書に判断を仰ぐ（全社ルール5） |

## 禁止事項

- 確認できていないことを、確認したように書かない。**推測で埋めない**
- 被害者・遺族・容疑者の個人が特定できる情報を書かない
- 断定できない段階で断定しない（「〜とみられる」「当局発表」を省かない）
- 他社の翻訳文や要約をそのまま使わない。一次情報から自分で日本語にする
- 投資・医療・法律の助言に踏み込まない。事実と出典までにとどめる
- 煽らない。恐怖や怒りで再生数を取りにいく書き方をしない
- **作り手が当事者のニュースは、事実と出典だけを書き、評価を書かない**
  （このオフィスを動かしている道具の提供元が登場する話題がこれにあたる）
