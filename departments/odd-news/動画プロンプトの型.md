# 動画プロンプトの型

日次5件から、縦型10秒のショート動画を作るための型。
**1件ごとに素材シートを1枚作り、そこから各ツールの形に流し込む。**

素材シートを間に挟むのは、ツールを乗り換えても原稿を作り直さずに済むようにするため。

```
日次5件 ──→ 素材シート（1件1枚） ──┬─→ 型1 アバター（読み上げ）
                                  ├─→ 型2 映像音声一括（映画的）
                                  └─→ 型3 映像のみ（音は後乗せ）
                                        │
                                        └─→ 投稿文（キャプション・ハッシュタグ）
```

## 本数の決めかた

| 型 | 中身 | 使いどころ |
|---|---|---|
| **型A：1件1本** | 1件を10秒で。1日5本 | 本命。毎日これを回す |
| **型B：5件まとめ1本** | 5件をテロップで流す | 週のまとめ。毎日は出さない |

---

# 尺と字数

日本語のナレーションは、ショート動画の速さで**1秒あたり約7字**。

**ここが報道の動画と決定的に違う。** 珍ニュースには**間（ま）が要る**。
オチの前で0.3〜0.5秒空けないと、面白い話が「情報」になって流れてしまう。

その分、詰められる字数が減る。**本文は45〜60字が上限**。
10秒のうち1.5〜3秒は、意図的に黙る時間に使う。

## 秒割り（型A）

| 秒 | 役割 | 書きかた |
|---|---|---|
| 0.0〜2.0 | **フリ** | ふつうに始める。まだ変な話だと悟らせない |
| 2.0〜2.3 | （間） | — |
| 2.3〜6.5 | **事実** | 数字を置く。ここがいちばんおかしい |
| 6.5〜7.0 | （間） | **いちばん大事な0.5秒** |
| 7.0〜8.5 | **オチ** | 変な一点をひとつだけ |
| 8.5〜10.0 | **締め** | 言い切って終わる |

### フリで煽らない

「衝撃」「ヤバい」「信じられない」で始めない。**先に驚かせると、オチで驚けなくなる。**
淡々と始めて、事実のほうに驚いてもらう。

**いちばん強いフリは、何でもないことのように言うこと。**

### オチは1つだけ

面白い点が3つある話でも、**動画に入れるのは1つ**。
残り2つはキャプションに書く。**10秒に3つ入れると、1つも残らない。**

## 秒割り（型B・5件まとめ）

| 秒 | 中身 |
|---|---|
| 0.0〜1.0 | 日付と「今日の5件」 |
| 1.0〜8.5 | 5件を1.5秒ずつ。1件は**全角12字以内**のテロップ1行 |
| 8.5〜10.0 | 「続きは説明欄」 |

# 素材シート（1件1枚）

```
【素材シート】YYYY-MM-DD ／ 第n件
見出し    ：（全角20字以内）
発表元    ：
発表日    ：
出典URL   ：（発表元＋報道の2本）
事実      ：（発表元から写した数字と固有名詞。3行以内）
フリ      ：（ふつうに始める1行）
オチ      ：（いちばん変な一点。ひとつだけ）
キーの数字 ：（画面に出す数字を1つだけ）
笑いの向き ：（何に向けて笑うか。人ではなく出来事の規模に）
3つの問い  ：笑われる人 □なし □笑われに来ている ／ 困っている人 □なし ／ 対立 □なし
画の方向  ：
避けるもの ：
```

**3つの問いの欄が全部埋まっていない素材シートは、動画にしない。**

## 画の引き出し

| 話の種類 | 画 |
|---|---|
| 途方もない手間 | 作りかけの全景を引きで。手元の寄り。積み上がった材料 |
| 変な競技 | 道具だけを並べる。土・砂・汗の質感 |
| 学術の珍テーマ | 古い論文の紙面（文字は読めない距離で）、実験器具 |
| 巨大なもの | 人の大きさと並べる。**縮尺が分かる画が命** |
| 役所と制度 | 判子、書類、掲示板 |
| 動物 | 実在の個体を再現させない。**種として一般的な画にとどめる** |

## 画で必ず避けるもの

- **実在の一般の人の顔・姿を再現させない。** 記録保持者も本人と分かる形にしない
- 企業のロゴ、商品のパッケージをそのまま再現させない
- 不幸・事故・怪我を思わせる画
- 人を見下ろす構図（見下す画になる）
- 「変な外国」に見せる演出。現地をばかにする画にしない

# ツール別の型

## 共通の前提

- 画面比 **9:16**（1080×1920）／ 尺 **10秒** ／ 1カット（場面転換なし）
- **文字を生成させない。** どのツールも日本語の文字は崩れる。書き出してから編集で乗せる
- テロップの置き場：上3分の2。画の主役は下3分の1に寄せる
- **オチをテロップに出さない。** 先に読まれて、音声のオチが死ぬ。
  画面に出すのは見出しとキーの数字まで。**オチは声だけで言う**
- 共通ネガティブ（型2・型3で使う）：

```
text, captions, subtitles, watermark, logo, brand packaging,
recognizable real person, celebrity likeness, distorted hands,
injury, blood, distress, fast cuts, meme text
```

## 型1：アバター型（読み上げ系のツール）

```
■ 台本（そのまま読み上げさせる。45〜60字）
（素材シートの フリ＋事実＋オチ＋締め をつないだ1本の文章）
※ 間を入れる箇所に、読点ではなく改行を置く。多くのツールは改行で息を継ぐ

■ アバター
性別・年齢感：（落ち着いた語り口。**面白がりすぎない**）
服装：無地。ロゴなし
姿勢：正面・上半身。身振りは小さく

■ 声
言語：日本語／速度：中くらい（**速くしない。間が消える**）
トーン：淡々と。オチも同じ調子で言い切る

■ 画面
9:16。背景は素材シートの「画の方向」。浅いぼけ
アバターの位置：画面の下3分の1。上3分の2はテロップ用に空ける
字幕：生成しない
```

**アバターに笑わせない。** 淡々と読むほうが面白い。
喋り手が面白がると、見ている側の笑う余地がなくなる。

## 型2：映像音声一括型（映像と音を一度に作る系のツール）

```
■ プロンプト（英語で書く。1段落）
A vertical 9:16, 10-second shot.
[被写体と場面].
[被写体の動き].
Camera: [1つだけ。slow push-in / static locked-off / slow pull-out].
Lens: [例：35mm, shallow depth of field].
Lighting: [例：flat overcast daylight].
Color: [例：muted earth tones].
Texture: [例：subtle film grain, no motion blur].
Audio: [環境音]. A calm Japanese voice narrates, unhurried, with a short pause
before the last sentence: "[台本45〜60字をそのまま]".
No on-screen text, no captions, no logos, no recognizable real people.

■ ネガティブ
共通ネガティブ ＋ （その件ごとに足すもの）
```

- `unhurried, with a short pause before the last sentence` を必ず入れる。**間の指定**
- カメラは1回の動きに絞る。10秒で寄って引いて回すと、何も見えない
- ナレーションは台本をそのまま埋める。**要約させない**

## 型3：映像のみ型（短い映像に特化した系のツール）

```
■ 映像プロンプト（1〜2文）
（短いほど安定する）
■ カメラ指定：push in / pull out / pan / static のいずれか1つ
■ 尺・比率：10秒 / 9:16
■ ネガティブ：共通ネガティブ ＋ その件ごと

■ 後で乗せるもの（編集で）
・ナレーション音声（台本45〜60字。**間を実際に空けて録る**）
・テロップ：見出し（全角20字以内）＋ キーの数字。**オチは載せない**
・出典：画面の下に小さく発表元の名前
・BGM：**オチの手前で音量を落とすか、一度止める**
・効果音：間の直後に1つだけ
```

**間を作れるのはこの型だけ。** 迷ったらこれにする。

# 投稿文の型

## 狙い

珍ニュースは、**コメント欄が伸びるかどうか**が全て。
「へえ」で終わらせず、**言いたくなる余白**を残す。

- 動画に入れなかった面白い点を、キャプションに1つ置く
- 最後に**短い問いかけ**を1行入れる（「これ、何年かかると思います？」）
- ただし**釣らない**。答えのない煽りは、次から見てもらえなくなる

## Instagram（リール）

```
（1行目：フック。動画のフックと同じ文言にしない。言い換える／全角25字以内）

（空行）
・（事実1）
・（事実2）
・（動画に入れなかった面白い点）

（問いかけ1行）

出典：（発表元の名前）（発表日）
（発表元のURL）

（ハッシュタグ 10〜15個）
```

## TikTok

```
（1行。全角30字以内）
（問いかけ1行）
#（ハッシュタグ 4〜6個）
```

出典URLは投稿後に自分でコメントして固定する。

## ハッシュタグの決めかた

| 層 | 数 | 例 |
|---|---|---|
| 広い層 | 2〜3 | 世界のニュース、海外の反応 |
| 話題の層 | 3〜5 | その件の固有名詞（国名、大会名、賞の名） |
| 形式の層 | 2〜3 | 毎日更新、10秒、雑学 |
| 英語 | 3〜4 | 海外の話を扱っているため |

**毎回同じ組み合わせを貼らない。** 話題の層は件ごとに入れ替える。

# 出す前の確認

- [ ] 台本は45〜60字か。**読み上げて10秒に収まったか（実測する）**
- [ ] 間を0.3〜0.5秒、オチの手前に置いたか
- [ ] オチは1つだけか。3つ入れていないか
- [ ] **オチをテロップに出していないか**
- [ ] 数字は発表元から写したか。媒体の見出しから写していないか
- [ ] 換算した数字に「約」が付いているか
- [ ] 発表日を書いたか。記事の日付を書いていないか
- [ ] **3つの問いを通したか**（笑われる人／困っている人／対立）
- [ ] 笑いの向きが、人ではなく出来事の規模に向いているか
- [ ] 実在の一般の人の顔・姿が映っていないか
- [ ] 一般の人の氏名を動画に出していないか
- [ ] 元の話より面白くしていないか（**盛っていないか**）
- [ ] 出典を画面か説明文のどちらかに出したか

**字数と尺の実測は、道具を持っている側が行う。** 推定値を書かない。
