# 取材元と、真偽の確かめかた

珍ニュースで一番こわいのは、**嘘を本当として配ってしまうこと**。
面白い話ほど速く広まり、面白い話ほど検証されずに転載される。

暗号資産のときは「発表元まで戻る」で足りた。
この分野はそれに加えて、**そもそも起きたのかどうか**から疑う。

---

# 1. 取材元

## 通信社の珍ニュース欄（出発点）

| 取材元 | 備考 |
|---|---|
| 主要通信社の「奇妙なニュース」欄 | 各社が独自に裏を取っている。ここが一番安全な出発点 |
| 公共放送の同種の欄 | 同上 |
| 地方紙の一次報道 | 現地でしか出ない話が拾える。ただし転載か一次かを見る |

**通信社の記事も、そのまま写さない。** 数字は発表元まで戻る。

## 発表元（ここまで戻る）

| 種類 | 取材元 |
|---|---|
| 記録の認定 | 記録認定機関の公式の記録ページ |
| 賞・学術 | 主催団体の公式発表、論文そのもの、大学の広報 |
| 展示・催し | 美術館・博物館・主催団体の公式ページ |
| 企業がやったこと | 企業の公式リリース |
| 役所・制度 | 自治体・官庁の告知、議会の議事録、判決文 |
| 動物 | 園・水族館・研究機関の公式発表 |
| 祭り・競技会 | 主催団体の公式ページ、大会の結果表 |

## 学術の珍テーマ

| 取材元 | 何が出るか |
|---|---|
| 珍研究を表彰している団体の公式発表 | 毎年秋。受賞理由の原文が読める |
| 学術誌の公式ページ | 論文の題と要旨。**題だけで判断しない** |
| 大学の広報 | 研究者本人の言葉 |

# 2. 真偽の確かめかた

## 掴みやすい嘘、4種類

| 種類 | 見わけかた |
|---|---|
| **風刺サイト** | 面白すぎる。媒体名を調べると「風刺」「パロディ」と自称している |
| **生成された画像・動画** | 出どころの投稿が匿名。同じ画が別の話にも使われている |
| **再浮上した古い話** | 同じ内容が数年前にも出ている。日付を入れて検索すると出てくる |
| **数字の独り歩き** | 媒体ごとに数字が違う。桁か単位がどこかで壊れている |

## 確かめる手順

1. **通信社が出しているか**を見る。出していれば、裏は一度取られている
2. **発表元の公式ページ**を探す。記録なら認定機関、賞なら主催団体、催しなら会場
3. **同じ話が過去にも出ていないか**を見る。再浮上なら扱わない
4. **数字を発表元から写す。** 媒体の見出しから写さない
5. **画像・動画が生成物でないか**を見る

**独立した2つの経路で取れないものは扱わない。**
「面白いから、たぶん本当だろう」で出さない。

## 数字が壊れる実例（2026-09-19）

世界最長の肉のおやつの記録を確かめたとき、媒体によって長さが3通りあった。

| 媒体の書きかた | 実際 |
|---|---|
| 429フィート5.4インチ | **これが正しい**（約130.9メートル） |
| 「230フィート近く」 | 記事の見出しと本文が食い違っていた |
| 「1.1308メートル」 | 桁が壊れている |

**媒体の数字は壊れる。** 記録認定機関の記録ページと、企業の公式リリースに戻れば1つに定まった。
見出しから写していたら、3分の2の確率で間違っていた。

## 換算のルール

海外の話はヤード・ポンド法で出てくる。日本向けに直すが、**直したことを分かるように書く**。

- 元の数字を先に、換算を後に書く（「429フィート5.4インチ＝約130.9メートル」）
- 動画では換算後だけを読んでよい。**まとめの文書には両方残す**
- 「約」を消さない。丸めたなら丸めたと分かるように

## 外国語のネタ

- 自動翻訳だけで判断しない。**固有名詞と数字は原語の表記を確認する**
- 現地の言い回しが笑いどころになっている話は、日本語にすると死ぬ。無理に訳さず外す
- 現地では笑い話でない可能性を考える（宗教・葬送・食べ物にまつわる話は特に）

# 3. この環境での引きかた

外部ページへの直接取得が、通信の出口で塞がれている先がある。
塞がれたら、検索の絞り込みで公式ドメインだけを指定して引く。
そうすれば媒体の記事が混ざらず、発表元に届いたかどうかが分かる。

**直接開けないことを理由に、媒体の記事で代用しない。**
検索でも発表元に届かなかったものは、その旨を書いて5件から外す。

---

# 4. 出典の残しかた

1件につき、次をすべて残す。

- **発表元**（組織名）
- **発表日**（記事を読んだ日ではない）
- **発表元の公式URL**
- **通信社などの報道URL**（あれば）
- **確認できなかった点**（あれば正直に書く）

出典のない話は、面白くても載せない。
