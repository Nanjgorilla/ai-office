# バーチャルオフィス

エージェントが依頼を受けて動く様子を、平面図の上で見るための場所。

ファイルの中身を追いかけなくても、**誰が動いているか**が灯りで分かる。

## 見かた

| 画面 | 意味 |
|---|---|
| 灯りのついた席 | その担当がいま動いている |
| 席から席へ飛ぶ書類 | 依頼・指示・報告が渡った |
| 朱印（済） | その担当から報告が上がった |
| 光る棚 | ファイルに残った（`secretary/` `inbox/` `departments/coconala/`） |
| 業務日誌 | 起きたことの一覧。新しいものが上 |

平面図は実際の組織のとおりに並べてある。外からの依頼はすべて受付を通り、
秘書役の席を経由してココナラ部門に渡る（全社ルール4）。
どこに回すか決まらないものは inbox の棚に入る（全社ルール5）。

手が空いている席は、目を閉じて色も落ちている。動き出すと目を開けて色が戻り、
報告が上がるとひとつ跳ねる。

## 席の人

顔の作りは全員同じで、**持ち物だけが違う**。名札を読まなくても、誰の席か分かるようにしてある。

| 席 | 持ち物 | なぜ |
|---|---|---|
| 依頼主 | 封筒 | 依頼を持って外から来る |
| 秘書役 | ヘッドセット | 電話と来客を受ける窓口 |
| 鑑定担当 | 筆 | 下書きを書く |
| チェック担当 | 虫眼鏡 | 画数と型を点検する |
| レビュー担当 | 帽子 | 外から来たお客様の目で読む |
| リサーチ担当 | 双眼鏡 | 外を見に行く |
| 出品ページ担当 | 鉛筆 | 文面を書く |
| 客員席 | ？ | まだ誰の席か決まっていない |

## スマホで見る

画面が狭いときは、**間取りが縦に組み替わる**。受付が上、ココナラ部門が下に来て、
席は2列に並ぶ。横に縮めて字が読めなくなることはない。横スクロールも出ない。

広い画面に戻せば、元の横並びに戻る。向きを変えたときも組み替わる。

## 開きかた

### はじめて動かすとき

このリポジトリで最初に Claude Code を立ち上げたとき、**フックを入れてよいか一度聞かれる**。
`.claude/settings.json` に書いたフックは、承認するまで動かない。承認すると、
それ以降のやり取りが `office/activity.jsonl` に記録されるようになる。

聞かれずに記録も始まらない場合は、承認がまだか、`python3` が見つかっていない。
`echo '{"hook_event_name":"SessionStart"}' | python3 .claude/hooks/office_log.py` を
手元で走らせて、`office/activity.jsonl` に1行増えるかどうかで切り分けられる。

### 毎日の動かしかた

1. `python3 office/server.py` を走らせておく（つけっぱなしでよい）
2. `http://localhost:8765/` を開いておく
3. いつもどおり Claude Code に頼む

右上が「実ログ」になっていれば、つながっている。席の灯りが、そのまま作業の状況になる。

### そのまま開く（デモ運転）

`office/index.html` をブラウザで開く。鑑定の流れ（下書き → 点検・初見 → 引き渡し）が
繰り返し再生される。何も動いていないときでも、オフィスの動きかたが分かる。

### 実際の動きを見る

```
python3 office/server.py
```

`http://localhost:8765/` を開く。右上の表示が「実ログ」に変われば、つながっている。
この状態で Claude Code に何か頼むと、その動きがそのまま平面図に出る。

止めるときは Ctrl+C。番号を変えたいときは `python3 office/server.py 9000`。

そのままファイルを開いた場合、ブラウザが記録の読み込みを止めるためデモ運転になる。
実際の動きを見るときは配信係を通す。

## 記録のしくみ

`.claude/settings.json` に登録したフックが、出来事のたびに
`.claude/hooks/office_log.py` を呼ぶ。記録係はそれを `office/activity.jsonl` に1行ずつ
追記し、平面図が1秒ごとに読みに行く。

| 出来事 | 記録される種類 |
|---|---|
| 会話のはじまり | 出社 |
| 人からの依頼 | 依頼（文字数だけ） |
| サブエージェントの呼び出し | 指示 |
| サブエージェントの完了 | 報告 |
| ファイルを読む・探す | 調べ物 |
| ファイルに書く | 執筆・保管 |
| 外部を見に行く | 外出 |
| ひと区切り | 手待ち |

### 本文は記録しない

このリポジトリにはお客様の実名を一切残さない（`departments/coconala/CLAUDE.md`）。
依頼文も鑑定文も、お名前を含みうる。だから記録係は**内容を一切書かない**。

残すのは、出来事の種類・担当者の名前・道具の名前・ファイルの場所・文字数だけ。
「誰が」「何をしていたか」は分かるが、「何と書いたか」は分からない。
それで平面図は十分に動く。

`office/activity.jsonl` 自体も `.gitignore` に入れてあり、commit されない。
その日の記録として残すべきものは、これまでどおり秘書役が `secretary/` に書く。
この記録は画面のためだけのもので、業務の記録ではない。

### 道具の記録に担当名が付かないことについて

ファイルを読む・書くといった記録には、それを誰がやったかが付かない。
そこで平面図は、**直近に呼ばれた担当のもの**として扱っている。
ふつうはそれで合うが、複数の担当が同時に動いているときは、
灯りが片方に寄ることがある。そこまでは見分けられない。

## フックを止めたいとき

`.claude/settings.json` の `hooks` を消すか、中身を空にする。
記録が止まるだけで、他の動きには影響しない。
記録係は何が起きても終了コード 0 で戻るので、記録に失敗しても仕事は止まらない。
